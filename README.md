## Необходимо разработать систему для генерации программного кода под различные языки программирования.

Система должна поддерживать:
1) генерацию классов;
2) генерацию методов;
3) генерацию операторов вывода;
4) возможность расширения для новых языков программирования без изменения клиентского кода.

В рамках лабораторной работы требуется реализовать поддержку:
C++, Java, C#.

Также необходимо обеспечить:
1) независимость клиентского кода от конкретных реализаций;
2) удобное расширение системы;
3) автоматическое управление памятью.
